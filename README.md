# ActivityTrack

ActivityTrack is a simple mobile application built using Flutter and Dart. 
This application helps users manage daily activities and monitor their progress through a counter feature.

## Features

- View a list of activities
- Add new activities
- Edit existing activities
- Track activity progress using a counter
- Increment and decrement counters
- Reset activity counters
- Simple and user-friendly interface
- Soft Blue UI design

## Technologies Used

- Flutter
- Dart
- Android Studio
- Visual Studio Code

## Architecture

This project uses the Model-View-ViewModel (MVVM) architecture to organize application code and separate responsibilities.
